# Первый проект на Django: Конвертер валют

Готовое веб-приложение на Django: конвертер валют с дополнительными служебными страницами. Проект полностью реализован и покрыт тестами.

## Возможности

- **Главная страница** (`/`) — список ссылок на все разделы приложения, ссылки строятся через `reverse()`.
- **Текущее время** (`/current_time/`) — серверное время и обновляемые каждую секунду часы на JavaScript.
- **Содержимое рабочей директории** (`/workdir/`) — список файлов директории, из которой запущен сервер.
- **О проекте** (`/about/`) — описание приложения и инструкция по использованию.
- **Конвертация валют** (`/convert/`) — пересчёт суммы между валютами по фиксированным курсам.

## Курсы валют

Курсы заданы фиксированным словарём `EXCHANGE_RATES` в [`app/views.py`](app/views.py):

| Пара валют | Курс |
|------------|------|
| USD → RUB | 84.1975 |
| EUR → RUB | 96.6671 |
| USD → EUR | 0.86 |
| EUR → USD | 1.15 |
| RUB → USD | 0.0118 |
| RUB → EUR | 0.0103 |

## Конвертация валют

### Параметры запроса (GET)

| Параметр | Описание | Пример |
|----------|----------|--------|
| `from` | Код исходной валюты | `USD` |
| `to` | Код целевой валюты | `RUB` |
| `amount` | Сумма для конвертации | `10` |

### Примеры

```
http://127.0.0.1:8000/convert/?from=USD&to=RUB&amount=10
→ 10.00 USD = 841.98 RUB

http://127.0.0.1:8000/convert/?from=EUR&to=RUB&amount=5
→ 5.00 EUR = 483.34 RUB

http://127.0.0.1:8000/convert/?from=RUB&to=USD&amount=1000
→ 1000.00 RUB = 11.80 USD
```

Коды валют регистронезависимы: `usd`, `USD` и `Usd` обрабатываются одинаково.

### Обработка ошибок

| Ситуация | Ответ |
|----------|-------|
| Параметры не переданы | `Пожалуйста, укажите параметры: from, to, amount` |
| Передана часть параметров | `Один или несколько параметров не заполнены` |
| Для пары валют нет курса | `Курс для пары GBP → JPY не найден` |
| `amount` не число | `amount not-a-number не является корректным числом` |
| `amount` равен `nan`/`inf`/`-inf` | отклоняется как некорректное число |

## Безопасность

- Все пользовательские данные (`from`, `to`, `amount`) экранируются через `escape()` перед выводом в HTML — защита от отражённого XSS.
- Имена файлов на странице `/workdir/` также экранируются.
- Функция `is_numeric()` дополнительно проверяет конечность числа через `math.isfinite()`, отсекая `nan` и `inf`.

## Запуск

```bash
pip install -r requirements.txt
python manage.py runserver
```

После запуска откройте в браузере: <http://127.0.0.1:8000/>

## Тесты

```bash
pytest
```

Всего 10 тестовых функций, которые раскрываются в 22 теста:

- главная страница: наличие всех ссылок;
- конвертация: успешные расчёты (4 варианта пар), отсутствие параметров, частичное заполнение, неизвестная пара валют, нечисловой `amount`;
- отклонение `nan`/`inf`/`-inf` (5 вариантов);
- экранирование XSS в параметрах конвертера (3 варианта) и в именах файлов рабочей директории;
- страницы времени, «О проекте» и рабочей директории.

Проверка покрытия кода:

```bash
pytest --cov=. --cov-report=term-missing
```

Тестовые фикстуры вынесены в [`tests/conftest.py`](tests/conftest.py): `enable_db_for_all_tests` (autouse), `valid_params` и `workdir_with_malicious_file` (подменяет рабочую директорию для теста экранирования имён файлов).
